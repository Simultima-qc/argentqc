# Ledger de claims - prestation-canadienne-travailleurs-2026

Revalidation (issue #81, 2026-09-05) : audit claim par claim de l'article `prestation-canadienne-travailleurs-2026.tsx`, jusqu'ici `explicitly-out-of-scope` (17 governed / 13 out-of-scope avant cette issue). Le slug de l'article n'a pas été renommé (conventions de routes hors périmètre de cette issue), mais tout le contenu visible corrige le nom du programme.

WebFetch vers `canada.ca` est bloqué (`EGRESS_BLOCKED`). Les valeurs ci-dessous s'appuient sur `WebSearch`, avec corroboration croisée sur au moins deux à trois sources indépendantes convergentes (page officielle ARC identifiée par titre exact, CFFP Université de Sherbrooke, Wealthsimple, Narcity/Noovo).

**Constat majeur** : le nom « Prestation canadienne pour les travailleurs (PCT) » utilisé dans tout l'article n'est plus le nom officiel du programme. Depuis l'année d'imposition 2019, le programme (anciennement « Prestation fiscale pour le revenu de travail ») s'appelle officiellement **« Allocation canadienne pour les travailleurs (ACT) »**, confirmé directement par le slug de la page officielle de l'ARC : `ligne-45300-allocation-canadienne-travailleurs-act.html`.
