## Résidu et incertitude

Aucune source de vérité versionnée n'existe dans `src/data/finance-2026/` pour les tranches d'imposition
fédérales/québécoises combinées, le crédit combiné âge/personne vivant seule/revenus de retraite du
Québec, ou les règles de fractionnement elles-mêmes : cet article reste gouverné par ce ledger seul
(pas de `datasetModule`), conformément au principe de ne pas créer de nouvelle infrastructure pour cette
issue. Si un futur audit centralise ces paramètres dans un module versionné (p. ex. un `tax-brackets-2026.ts`
ou une extension de `tax-2026.ts`), ce ledger devra être relié à ce module plutôt que dupliqué.

Risque principal restant : les montants indexés 2026 exacts du volet retraite du crédit combiné québécois
n'ont pas pu être confirmés directement (accès Revenu Québec bloqué dans cet environnement). L'article a
été rédigé pour rester correct même sans ces chiffres précis (mécanisme décrit + renvoi vers le site
officiel pour les paramètres de l'année courante), mais une revalidation directe est recommandée dès
qu'un accès à `revenuquebec.ca` est possible.
